# Simulate Crawler Access robots txt status codes

This Python script simulates how search engine crawlers might interact with a website. It checks the robots.txt file for access permissions and then attempts to fetch a specific URL, reporting HTTP status codes. It highlights how crawlers see sites differently than humans.

## Language

`python`

## How to Run

Run this script using Python: `python crawler_simulator.py`
